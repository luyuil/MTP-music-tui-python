music-tui 歌单选择功能开发手册
================================================================
目标：启动后先显示"歌单列表"（~/Music 下的文件夹），
      上下键选择，Enter 进入歌单，载入该文件夹的歌曲，
      然后进入现有的队列 / 歌词 / 封面界面。

背景变化：
  ~/Music 已经从"平铺 4 首歌"改成"按歌单分文件夹"：
    中文   21 首
    日语   42 首
    纯音乐 11 首
    其他   23 首
    lrc/   歌词目录（不是歌单）
  共 97 首。

这一版只做"启动选歌单 + 载入文件夹"，
不重写队列、歌词、封面、翻页。


零、这一版做什么 / 不做什么
----------------------------------------------------------------
做：
  - 扫描 ~/Music 顶层的文件夹，排除 lrc/
  - 新做一个歌单选择界面：文件夹图标 + 名字 + 上下键 + Enter
  - Enter 后把该文件夹的歌曲载入 MPD 队列，切到主界面
  - 把现有歌词文件迁移到 lrc/<歌单名>/ 下

不做：
  - 从歌单界面按 Esc 返回（可选扩展）
  - 歌单内搜索、歌单自定义顺序、显示歌曲数量
  - 记住上次选中的歌单
  - 从 MPD 读目录（这一版用文件系统）


一、先看清现状（改之前必须知道）
----------------------------------------------------------------
1. 配置
   src/music_tui/config/__init__.py 里已有：
     MUSIC_DIR = Path.home() / "Music"
     LRC_DIR   = MUSIC_DIR / "lrc"

2. 主界面
   MusicTui.compose() 现在是：
     #tabs（song / cover / visualization）
     #body（QueuePane#queue + Vertical#right）
     StatusBar

3. 启动
   on_mount() 里：
     svc = MpdService(); svc.start()
     set_focus(#queue)
     set_interval(0.1, _pump)
     _update_tabs()

4. 队列
   QueuePane 显示的是 MPD 的播放队列。
   MPD 状态 / 队列变化由 _pump 消费：
     QueueEvent -> QueuePane.set_songs(ev.songs)
     StatusEvent -> _apply_status()

5. MPD 服务
   MpdService.send(command, *args) 把命令丢进命令线程。
   _execute() 里已经有两个特殊命令：
     __status__  -> 推 StatusEvent
     __cover__   -> 推 CoverEvent
   普通命令直接 getattr(client, command)(*args)。

6. 歌词
   lyrics_path(uri) 的规则是：
     LRC_DIR / Path(uri).with_suffix(".lrc")
   以前 uri 是 "Michita - Cry For Me.mp3"；
   现在 uri 会变成 "日语/Michita - Cry For Me.mp3"。
   所以歌词必须放到：
     ~/Music/lrc/日语/Michita - Cry For Me.lrc
   否则进入歌单后所有歌词都会显示"暂无歌词"。

7. 翻页
   PAGES / _switch_page() 操作的是 #pages 和 #body，
   包一层主界面容器后这些 query_one 仍然有效，不用改。


二、关键设计决定（先定下来，再写代码）
----------------------------------------------------------------
1. 歌单列表从文件系统读，不从 MPD 读
   理由：
     - 启动时 MPD 可能还没连上；
     - 可以方便地排除 lrc/ 和隐藏目录；
     - 排序可控。
   MPD 只负责"把选中的文件夹加进队列"。

2. 顶层用 ContentSwitcher 切"歌单页 / 主界面"
   不 push_screen，不开第二个 Screen。
   结构：
     Screen
       └── ContentSwitcher#root
             ├── PlaylistPane#playlist-screen
             └── Vertical#main-screen
                   ├── #tabs
                   ├── #body
                   └── StatusBar
   好处：只有一个 App，状态简单；主界面控件照常挂载。

3. 载入文件夹用一条特殊命令 __folder__
   不要在 UI 里连续 send("clear")、send("add")、send("play")。
   一条命令在命令线程里一次做完，顺序绝对可靠，
   也不会在三条命令之间插入别的命令。

4. 用一个 _mode 标志分流按键
   self._mode = "playlist" 或 "main"
   上下 / Enter / 空格 / 左右都先看 _mode。

5. 歌单顺序
   用 sorted(..., key=lambda p: p.name)。
   注意：这是 Unicode 顺序，你的四个文件夹实际会排成：
     中文、其他、日语、纯音乐
   如果以后想固定成"中文、日语、纯音乐、其他"，
   在 config 里加一个 PLAYLIST_ORDER 列表，按列表下标排序。

6. 文件夹图标
   在 config 里加 PLAYLIST_ICON = "📁"。
   如果终端里显示成方块或宽度不对，换成 "▸" 或 "🗀"。

7. 空文件夹
   允许它出现在列表里。
   进入后 MPD 队列为空，界面显示"队列为空"，不能崩。

8. 进入歌单后默认播放第一首
   用 client.play(0)。
   如果只想载入不播放，把这一步去掉即可。

四、卡 1：扫描歌单 core/playlists.py
----------------------------------------------------------------
【1.1】先在 config 里加两个常量

  PLAYLIST_ICON = "📁"
  IGNORED_PLAYLIST_NAMES = {"lrc"}

  说明：
    - lrc 就在 MUSIC_DIR 里，不排除的话会出现在歌单列表里；
    - 以后如果还有 "封面" 之类的目录，也加进这个集合。

【1.2】Playlist 数据类

  @dataclass(frozen=True)
  class Playlist:
      name: str
      path: Path

  说明：
    - name 是文件夹名，也是显示名；
    - path 是绝对路径，现在 UI 用不到，但测试和以后
      "统计歌曲数 / 读取封面" 会用；
    - frozen=True，和 Song / LyricLine 保持一致。

【1.3】扫描函数

  签名：
    def scan_playlists(music_dir: Path) -> list[Playlist]:

  参数：音乐根目录（传 MUSIC_DIR）
  返回：按名字排序的 Playlist 列表；没有歌单时返回 []

  步骤：
    1. if not music_dir.is_dir(): return []
    2. 用 music_dir.iterdir() 拿到所有直接子项；
       捕获 OSError（权限问题等），出错返回 []
    3. 逐个过滤：
         - 不是目录（p.is_dir() 为 False）-> 跳过
         - p.name 在 IGNORED_PLAYLIST_NAMES 里 -> 跳过
         - p.name 以 "." 开头 -> 跳过（隐藏目录）
         - 其余生成 Playlist(p.name, p)
    4. 按 p.name 排序
    5. return

  可用函数 / 方法：
    Path.is_dir()
    Path.iterdir()
    Path.name
    sorted(..., key=lambda p: p.name)
    list.append()

【1.4】边界

  - MUSIC_DIR 不存在：返回 []；
  - 没有子目录：返回 []；
  - 目录没有读权限：捕获 OSError，返回 []（不要让它崩 App）；
  - 只有 lrc/：返回 []；
  - 子目录里没有音频：仍然返回（是否过滤是以后的事）；
  - 只看顶层，不递归（歌单里的子目录由 MPD 的 add 递归处理）。

【1.5】单测（和代码一起写）

  新建 scripts/test_playlists.py：
    from music_tui.core.playlists import Playlist, scan_playlists

  测试点：
    1) tmp_path 下建 中文/、日语/、lrc/、.hidden/、一个普通文件；
       断言只返回 中文、日语，且顺序正确；
    2) 空目录 -> []；
    3) 不存在的目录 -> []；
    4) 返回的 Playlist.name 和 .path 对得上。

  运行：
    .venv/bin/pytest scripts/test_playlists.py -v


五、卡 2：MPD 载入文件夹 services/mpd.py
----------------------------------------------------------------
【2.1】MpdService 新方法

  签名：
    def load_folder(self, folder: str) -> None:

  职责：把"载入一个歌单"这件事丢给命令线程。
  实现只需要：
    self.send("__folder__", folder)

  说明：
    - folder 是相对路径，例如 "中文"、"日语"；
    - 不要在这里拼 MUSIC_DIR，MPD 的 add 用的是相对 music_directory 的路径。

【2.2】_execute 里加分支

  在 __cover__ 分支后面加一个：
    elif command == "__folder__":
        folder = args[0]
        client.clear()
        client.add(folder)
        尝试 client.play(0)，捕获 CommandError

  为什么用一条特殊命令：
    - clear() 会停播并清空队列；
    - add(folder) 会递归加入该目录下所有歌曲；
    - play(0) 播放第一首；
    - 三件事在同一个命令线程里一次完成，不会被别的命令插队。

  为什么 play(0) 要 try/except：
    空文件夹 add 之后队列仍是空的，play(0) 会抛 CommandError。
    这不是错误，UI 继续显示"队列为空"即可。

【2.3】验证（先不用 UI）

  手动确认 MPD 能识别这些文件夹：
    mpc ls
    mpc clear
    mpc add 中文
    mpc playlist | head
    mpc play 0

  如果 mpc add 中文 没有反应：
    - 确认 MPD 的 music_directory 是 /home/lwq/Music；
    - 跑一次 mpc update；
    - 看 mpc ls 里有没有 "中文"。

【2.4】边界

  - 文件夹名带空格/中文：直接传字符串，MPD 支持 UTF-8；
  - 文件夹里有子目录：add 会递归加入，不需要逐个 add；
  - MPD 没连上：命令线程会重连，UI 先切到主界面，
    等连上后队列再填充；
  - 空文件夹：队列为空，不崩。


六、卡 3：歌单控件 widgets/playlists.py
----------------------------------------------------------------
【3.1】结构

  PlaylistPane(Pane)
    ├── Static("选择歌单", id="playlist-title")
    └── VerticalScroll#playlist-scroll
          └── Static(id="playlist-body")

  Pane 已经有 can_focus，焦点可以直接放在 PlaylistPane 上。
  边框已经在 app 的 CSS 里去掉了，这里不用再管边框。

【3.2】字段

  selected = reactive(0)          # 和 QueuePane 一样
  self._names: list[str] = []     # 当前显示的文件夹名

【3.3】要写的方法

  1) compose(self) -> ComposeResult
     产出上面那三个控件。
     注意：Pane 的默认 compose 是产出一个 body Static，
     这里重写它，所以不要再调 super().compose()。

  2) set_playlists(self, names: list[str]) -> None
     - self._names = names
     - self.selected = 0
     - 调一次 _redraw()

  3) move(self, delta: int) -> None
     - 没有歌单就直接 return
     - selected = (selected + delta) % len(names)
     - reactive 变化会自动触发 watch_selected -> _redraw

  4) current_name(self) -> str | None
     - 空列表返回 None
     - 否则返回 self._names[self.selected]

  5) watch_selected(self) -> None
     - 调 _redraw()

  6) _redraw(self) -> None
     - query_one("#playlist-body", Static)
     - 空列表：显示"没有找到歌单"
     - 非空：逐行生成
         选中：  [reverse]📁 名字[/]
         非选中：  📁 名字
     - 用 config 里的 PLAYLIST_ICON，不要写死
     - 名字用 rich.markup.escape(name)，防止文件夹名里的
       "[" 被当成 Rich 标记（之前歌词里踩过这个坑）

【3.4】可用 API

  self.query_one("#playlist-body", Static)
  body.update("\n".join(lines))
  reactive / watch_selected
  from rich.markup import escape

  参考实现：widgets/queue.py 的 set_songs / move / _redraw，
  把"歌曲"换成"文件夹名"，把图标换成 PLAYLIST_ICON。

【3.5】边界

  - names 为空：显示占位，move 不动作，current_name 返回 None；
  - 只有一个歌单：上下键原地不动；
  - 名字里有 "["：escape；
  - 文件夹很多：VerticalScroll 负责滚动，不额外处理；
  - 📁 在终端里占 2 列：Textual 会按 wcwidth 处理，
    如果某些字体显示成方块，把 PLAYLIST_ICON 换成 "▸"。

【3.6】可选：样式

  #playlist-title { height: 1; padding: 1 2 0 2; color: $text-muted; }
  #playlist-scroll { height: 1fr; }
  #playlist-body { padding: 0 2; }


七、卡 4：app.py 接线
----------------------------------------------------------------
【4.1】新字段

  在 __init__ 里加：
    self._mode: str = "playlist"        # "playlist" | "main"
    self._playlists: list[Playlist] = []

  _playlists 保存扫描结果，后面"返回歌单 / 显示数量"会用。

【4.2】compose 重构

  现在的结构：
    #tabs
    #body
    StatusBar

  改成：
    ContentSwitcher(initial="playlist-screen", id="root")
      ├── PlaylistPane("playlists", id="playlist-screen")
      └── Vertical(id="main-screen")
            ├── #tabs
            ├── #body
            └── StatusBar

  注意：
    - 原来的 tabs/body/StatusBar 原样搬进 #main-screen，
      里面的 query_one("#body")、query_one("#pages") 都不用改；
    - #root 和 #main-screen 都要 height: 1fr；
    - #playlist-screen 要 width/height: 1fr。

  CSS 最少加：
    #root { height: 1fr; }
    #main-screen { width: 1fr; height: 1fr; }
    #playlist-screen { width: 1fr; height: 1fr; }

【4.3】on_mount 改三行

  现在：
    self.svc = MpdService(); self.svc.start()
    self.set_focus(self.query_one("#queue"))
    self.set_interval(0.1, self._pump)
    self._update_tabs()

  改成：
    1. 还是先启动 svc
    2. 调 self._load_playlists()
    3. set_focus 改为 PlaylistPane
    4. 保留 set_interval 和 _update_tabs

  说明：
    - MPD 服务照常启动，_pump 照常跑；
    - 主界面虽然隐藏，控件已经挂载，不需要延迟创建。

【4.4】_load_playlists

  签名：
    def _load_playlists(self) -> None:

  步骤：
    1. self._playlists = scan_playlists(MUSIC_DIR)
    2. names = [p.name for p in self._playlists]
    3. self.query_one(PlaylistPane).set_playlists(names)

  需要的 import：
    from music_tui.config import MUSIC_DIR
    from music_tui.core.playlists import Playlist, scan_playlists
    from music_tui.widgets.playlists import PlaylistPane

【4.5】_enter_playlist

  签名：
    def _enter_playlist(self) -> None:

  步骤：
    1. if self._mode != "playlist" or self.svc is None: return
    2. name = self.query_one(PlaylistPane).current_name()
    3. if name is None: return
    4. self.svc.load_folder(name)
    5. self._mode = "main"
    6. root = self.query_one("#root", ContentSwitcher)
       root.current = "main-screen"
    7. self.set_focus(self.query_one("#queue"))
    8. self._update_tabs()

  说明：
    - 先切界面再等队列事件也行；队列事件到了 QueuePane 会自己刷新；
    - 不要在这里阻塞等待 MPD，命令是异步的。

【4.6】按键分流

  现在四个 action 都直接操作队列，加上 _mode 判断：

  action_row_down / action_row_up
    _mode == "playlist" -> PlaylistPane.move(±1)
    _mode == "main"     -> QueuePane.move(±1)

  action_play_selected
    _mode == "playlist" -> self._enter_playlist()
    _mode == "main"     -> 原来的 QueuePane 播放逻辑

  action_play_pause
    _mode == "playlist" -> 直接 return
    _mode == "main"     -> svc.toggle()

  action_page_prev / action_page_next
    _mode == "playlist" -> 直接 return
    _mode == "main"     -> 原来的 _switch_page

  q 不用改，任何时候都能退出。

【4.7】_pump 要不要改

  可以完全不动。
  歌单界面显示时，_pump 仍会更新隐藏的队列/歌词/封面，
  不会报错，只是多做一点事。

  如果想让歌单界面更省：
    if self._mode == "main" and self._last is not None:
        再做 progress / set_position

  第一版建议不改，减少变量。

【4.8】CSS 提醒

  主界面原来没有边框，歌单页也不加边框。
  歌单页只是"标题 + 列表"，保持和现在风格一致。

  如果 #playlist-screen 的尺寸不对，优先检查：
    - #root 有没有 height: 1fr；
    - #main-screen / #playlist-screen 有没有 height: 1fr。

九、重要：迁移现有歌词目录
----------------------------------------------------------------
现在歌词是平铺的：
  ~/Music/lrc/Michita - Cry For Me (feat. Ami).lrc
  ~/Music/lrc/王忻辰&苏星婕-去年花开.lrc
  ~/Music/lrc/Ba+-+Duvet.lrc
  ~/Music/lrc/松下優也 - Mr.“Broken Heart” (Instrumental).lrc

歌曲现在在子目录里，lyrics_path(uri) 会把歌单名算进去，
所以歌词也要跟着进子目录：

  ~/Music/lrc/日语/Michita - Cry For Me (feat. Ami).lrc
  ~/Music/lrc/中文/王忻辰&苏星婕-去年花开.lrc
  ~/Music/lrc/其他/Ba+-+Duvet.lrc
  ~/Music/lrc/纯音乐/松下優也 - Mr.“Broken Heart” (Instrumental).lrc

迁移命令（先确认目标目录不存在同名文件）：

  mkdir -p ~/Music/lrc/中文 ~/Music/lrc/日语 ~/Music/lrc/纯音乐 ~/Music/lrc/其他
  mv ~/Music/lrc/Michita*.lrc   ~/Music/lrc/日语/
  mv ~/Music/lrc/王忻辰*.lrc    ~/Music/lrc/中文/
  mv ~/Music/lrc/Ba+-+Duvet.lrc ~/Music/lrc/其他/
  mv ~/Music/lrc/松下*.lrc      ~/Music/lrc/纯音乐/

验证：

  .venv/bin/python -c "
  from music_tui.core.lyrics import lyrics_path
  print(lyrics_path('日语/Michita - Cry For Me (feat. Ami).mp3'))
  "

  输出应该是 ~/Music/lrc/日语/...lrc。

注意：
  - lrc/ 本身必须被 scan_playlists 排除，否则它会变成一个歌单；
  - 日语/松下優也 - Mr. Broken Heart.mp3 和
    纯音乐/松下優也 - Mr.“Broken Heart” (Instrumental).mp3
    是两个文件，占位歌词只对应纯音乐那个，不要放错；
  - 其他/ 里同时有 Ba+-+Duvet.flac 和 Bôa - Duvet.mp3，
    现有 LRC 只对应 Ba+-+Duvet.flac。

十一、卡住时怎么排查
----------------------------------------------------------------
1. 歌单列表是空的
   - 打印 MUSIC_DIR，确认路径；
   - 打印 scan_playlists(MUSIC_DIR) 的返回值；
   - 确认目录有读权限；
   - 确认不是全被 IGNORED_PLAYLIST_NAMES 排除了。

2. lrc 出现在歌单里
   - IGNORED_PLAYLIST_NAMES 里有没有 "lrc"；
   - scan_playlists 的过滤步骤有没有漏。

3. 按 Enter 没反应
   - _mode 是不是 "playlist"；
   - PlaylistPane.current_name() 是不是 None；
   - self.svc 是不是 None；
   - #root 的 id / current 写对没有。

4. 进入后队列是空的
   - mpc ls 里有没有这个文件夹；
   - mpc add 中文 能不能加歌；
   - 文件夹里有没有音频；
   - MPD 有没有 update。

5. 中文文件夹 add 不进去
   - 确认 MPD 的 music_directory 和 UTF-8；
   - 用 mpc add "中文" 手动试。

6. 歌词全是"暂无歌词"
   - 歌词有没有迁移到 lrc/<歌单名>/；
   - 打印 lyrics_path(uri) 看实际路径；
   - 文件名和音频是否完全一致。

7. 📁 显示成方块
   - 换 PLAYLIST_ICON = "▸" 或 "🗀"；
   - 或者用 "[b]▸[/]" 之类的纯文本。

8. 排序不是想要的
   - 现在是 Unicode 排序：中文、其他、日语、纯音乐；
   - 要固定顺序，加 PLAYLIST_ORDER 列表，按列表下标排。
