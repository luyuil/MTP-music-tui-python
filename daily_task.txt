签名和返回值
项	说明
参数	gray: Image.Image，必须是 "L" 模式的灰度图
返回	int，0–255 之间的阈值
不修改	不改动传入的图片
Otsu 的步骤（照着实现）

    hist = gray.histogram() → 长度 256 的列表，hist[v] 是灰度 v 的像素个数；
    total = sum(hist)；total == 0 → 直接返回 128；
    sum_all = sum(i * h for i, h in enumerate(hist))；
    维护两个累加量，从 t = 0 扫到 255：
        w_b += hist[t]（背景像素数）
        sum_b += t * hist[t]（背景灰度总和）
    每一轮算出两类：
        背景均值 m_b = sum_b / w_b
        前景均值 m_f = (sum_all - sum_b) / (total - w_b)
        类间方差 v = w_b * (total - w_b) * (m_b - m_f) ** 2
    记录使 v 最大的那个 t，最后返回它。

边界：

    w_b == 0 或 total - w_b == 0 时跳过（除零）；
    整张图全黑或全白（所有像素同值）→ 所有方差都是 0 → 返回 128；
    图很小（比如 2×4 的测试图）→ 算法照样能用，但结果参考价值不大。
